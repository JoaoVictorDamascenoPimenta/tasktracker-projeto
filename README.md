# TaskTracker

## Descrição do projeto

O TaskTracker é um sistema de gerenciamento de tarefas desenvolvido em Python para ajudar o usuário a organizar suas atividades diárias, acompanhar prioridades e controlar prazos.

## Funcionalidades previstas

- Cadastrar novas tarefas.
- Visualizar as tarefas cadastradas.
- Definir título, descrição, prioridade e data limite.
- Iniciar cada tarefa com o status Pendente.
- Validar o preenchimento do título e a prioridade informada.

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Estrutura do projeto

A organização do projeto contará com as pastas `docs` e `src`. A pasta `docs` armazenará o planejamento lógico, enquanto `src` conterá o código-fonte do sistema.
